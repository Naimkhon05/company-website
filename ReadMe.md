GreenVisaGlobal – Accessible Web Application

Author: Naimkhon Ishonboboev

Project Description

GreenVisaGlobal is a responsive and accessible multi-page website created for a visa assistance service. The website provides information about visa support services, company background, and a contact form for client inquiries.

The purpose of this project is to demonstrate skills in:

semantic HTML5 structure

responsive web design

accessibility implementation (WCAG 2.2 Level AA)

usability and UX best practices

modern CSS layout techniques

The website was developed as a final university project reflecting real-world web development standards.

Website Pages

The project includes the following pages:

1. Home Page (index.html)

Hero section with call-to-action

Services overview

Navigation menu

Responsive layout

Accessible button interactions

2. About Page (about.html)

Company description

Mission and values

Structured headings for readability

Accessible list formatting

3. Contact Page (contact.html)

Fully accessible contact form

Input fields with labels

Required fields clearly marked
